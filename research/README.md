# Research notes

Saved research from the Everyday AI Research Agent (`.claude/agents/research-agent.md`). These are **internal source material**, not public content. Anything marked UNVERIFIED must be checked again before it's used in public content.

## File naming

`research/YYYY-MM-DD-short-descriptive-topic.md`, e.g. `research/2026-09-28-chatgpt-voice-mode-uk.md`

Keep everything in this one folder until there are enough notes to need subfolders.
